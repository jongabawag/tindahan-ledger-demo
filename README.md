# Tindahan Ledger — Demo

A static, browser-only demo of [Tindahan Ledger](https://github.com/Trei-Stacks/tindahan-ledger): a mobile-first daily checklist, cash count and customer-credit (utang) app for a small Philippine sari-sari store. Built with React + Vite + Bootstrap.
